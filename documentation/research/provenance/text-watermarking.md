# Text watermarking: SynthID-Text

> **TL;DR** Statistical watermarks bias an LLM's token sampling so a detector can later say "probably generated by model X". Google DeepMind's SynthID-Text is the leading open example (published in *Nature* in October 2024, open-sourced, in Hugging Face Transformers ≥ 4.46). It only works for models that embed it, which Claude does not publicly advertise *(unverified)*. It weakens under paraphrase and editing, and it gives probabilities, not provenance. **Hold.** Record provenance at generation time instead.

## What it is

SynthID-Text uses tournament sampling to embed a signal in token choice without visibly changing quality. A keyed detector scores new text for the signal. Google's own docs note limits. It is weaker on factual responses, where there is less freedom in word choice, and confidence drops sharply when text is thoroughly rewritten or translated. Third-party robustness tests report detection falling substantially under moderate paraphrase *(figures vary by study; secondary sources only)*.

## Why it matters for gentext

It is tempting as a way to answer "which sentences came from an AI?" after the fact. But our copy passes through human editing and length-fitting, which is exactly the regime where watermarks fade. Our AI text also comes mainly from Claude, not a SynthID-enabled model.

## How it would fit

It wouldn't, as a core mechanism. At most, an M7 check could flag suspected unlabelled AI text for human review, with the result stored as *evidence*, never as attribution.

## Strengths
- Needs no cooperation from downstream tools once embedded.

## Weaknesses / risks
- Model-specific. Opaque. Probabilistic. Degrades with edits. It cannot say *which* prompt or inputs produced the text.
- False positives would wrongly label staff or partner text as AI-generated, which is a real reputational risk.

## Verdict rationale

Hold. Declared generation records ([LLM generation records](llm-generation-records.md)) are deterministic, inspectable, and already in our control.
